### 1. 💡 Ẩn dụ thực tế: "Đo độ bao phủ code" (Code Coverage) là gì?

Giả sử dự án của bạn có **1.000 dòng code Java** xử lý các tính năng (đăng ký, đăng nhập, đặt hàng, áp mã giảm giá, hủy đơn...).
- Khi các lập trình viên viết các bài test tự động (Unit Test / Integration Test), câu hỏi đặt ra là: **"Bộ test của chúng ta đã kiểm tra được bao nhiêu % số dòng code trong dự án? Có dòng code nào bị bỏ sót chưa được test không?"**
- **JaCoCo (Java Code Coverage):** Là "thước đo" đếm xem trong 1.000 dòng code đó, có bao nhiêu dòng đã được test chạy qua (hiển thị màu xanh) và bao nhiêu dòng chưa từng được test tới (hiển thị màu đỏ).
- **File `test-coverage.ps1`:** Là **Robot tự động đo đạc**. Khi chạy lệnh này, nó sẽ tự động chạy toàn bộ các bài test Java, đo chỉ số %, và tạo ra một báo cáo trang web xem chi tiết từng file code đạt bao nhiêu % kiểm thử.

---

### 2. ⚙️ Quy trình tự động bên trong file `test-coverage.ps1`

Khi lệnh chạy, script sẽ tự động thực hiện 5 bước chuyên nghiệp:

1. **Kiểm tra môi trường:**
   - Kiểm tra xem máy bạn đã cài `docker` và `mvn` (Maven) chưa, đồng thời đảm bảo MySQL container (`shoeshop-mysql`) đang chạy.

2. **Tạo Database tạm thời cách ly (Isolated Database):**
   - Để tránh làm bẩn hoặc hỏng dữ liệu gốc, script tự tạo ra 1 database tạm với tên ngẫu nhiên (ví dụ: `shoeshop_cov_1f3cca...`).

3. **Chạy các bài test Java & Đo đạc bằng JaCoCo:**
   - Kích hoạt Maven và plugin **JaCoCo** (`jacoco-maven-plugin`) để chạy toàn bộ các bài test nội bộ trong dự án Java.
   - Trong quá trình test chạy, JaCoCo sẽ ghi lại chính xác từng hàm, từng nhánh lệnh `if/else` nào đã được thực thi.

4. **Xuất báo cáo HTML đẹp mắt:**
   - Tạo ra file báo cáo trang web tại đường dẫn: [`target/site/jacoco/index.html`](file:///c:/shoeshopp/Testing/target/site/jacoco/index.html).
   - Trang báo cáo này hiển thị bảng thống kê chi tiết tỷ lệ % bao phủ code của từng Package, Class, Method.

5. **Dọn dẹp tự động (Clean up):**
   - Xóa bỏ hoàn toàn database tạm vừa tạo, khôi phục lại cấu hình ban đầu để giữ cho hệ thống luôn sạch sẽ.

### ❓ Lỗi này là lỗi gì?

Lỗi **`java.net.ConnectException: Connection refused: connect`** / **`Communications link failure`** xảy ra do **Sai cổng kết nối Cơ sở dữ liệu (Database Port Mismatch)**:

1. Mặc định mã nguồn cấu hình cổng kết nối MySQL là **3306** (trong file `application.properties`).
2. Tuy nhiên, trên hệ thống Docker của bạn, container MySQL (`shoeshopp-mysql`) đang mở ở cổng **3307** (`localhost:3307`).
3. Khi bạn gõ thủ công lệnh `mvn test -Dtest="VoucherTests,..."` mà **không truyền tham số đổi cổng kết nối sang 3307**, Spring Boot sẽ cố kết nối vào cổng 3306 (vốn không có MySQL hoạt động) $\rightarrow$ dẫn đến lỗi ngắt kết nối database làm 5 test case bị `IllegalStateException: Failed to load ApplicationContext`.
